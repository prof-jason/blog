# Writing Prompt Generator

Students roll a die to get a writing subject, tap the card to get an AI-generated writing prompt for it, and tap again to flip the card and see an example response.

## Stack

- `frontend/`: Next.js (App Router, TypeScript, Tailwind). It's built as a static export.
- `backend/`: FastAPI project managed with uv. It serves `/api/*` and the exported frontend on the same origin.
  - `POST /api/prompts` `{subject}` returns `{subject, prompt, example}`, generated by an LLM with structured outputs (LiteLLM → OpenRouter, provider preference Cerebras; see `app/llm.py`).
  - `POST /api/auth/signup`, `POST /api/auth/login`, `POST /api/auth/logout`, `GET /api/auth/me` use cookie sessions.
  - SQLite (`users`, `sessions`), recreated from scratch every time the server starts.
- `Dockerfile`: a multi-stage build (Node builds the frontend, Python serves it).

## Running

You need Docker and a `.env` in the project root containing `OPENROUTER_API_KEY=...`.

```bash
scripts/start-mac.sh      # or start-linux.sh / start-windows.ps1
# → http://localhost:8000
scripts/stop-mac.sh       # or stop-linux.sh / stop-windows.ps1
```

## Development

```bash
# Backend (http://localhost:8000)
cd backend && uv run uvicorn app.main:app --reload

# Frontend (http://localhost:3000). next dev proxies /api to :8000
cd frontend && npm install && npm run dev
```

## Tests

```bash
cd backend && uv run pytest                       # LLM mocked
cd backend && RUN_LIVE_LLM=1 uv run pytest        # also makes one real LLM call
cd frontend && npm test
```
