# Writing Prompt Generator

Students in grades 4–6 see a writing subject with an AI-generated prompt on the front of a card, tap the card to flip it over for an example response, and roll the die for a new subject and prompt.

## Stack

- `frontend/`: Next.js (App Router, TypeScript, Tailwind). It's built as a static export.
- `backend/`: FastAPI project managed with uv. It serves `/api/*` and the exported frontend on the same origin.
  - `GET /api/prompts/stored` returns a random pre-generated prompt (404 if none yet); the page opens on one so the first card costs no request.
  - `POST /api/prompts` `{subject}` returns `{subject, prompt, example}`, generated by an LLM with structured outputs via LiteLLM → OpenRouter's `openrouter/free` router, which picks a free model per request (see `app/llm.py`). Free models share OpenRouter's daily free-request limit per account.
    - **Fallback prompts:** on startup, a background thread pre-generates `PROMPT_WARM_UP_COUNT` prompts (default 10, one per random subject) in a **single request**, since the free tier limits requests, not output size. It keeps every usable entry, and makes one more request for the missing subjects only if fewer than half came back usable (at most 2 requests per startup). If live generation fails, the endpoint serves a stored prompt for the same subject if there is one, otherwise any stored prompt (`"source": "stored"`, with that prompt's own subject). It returns a 502 only if nothing is stored yet. `GET /api/health` reports how many prompts are stored.
  - `POST /api/auth/signup`, `POST /api/auth/login`, `POST /api/auth/logout`, `GET /api/auth/me` use cookie sessions.
  - SQLite (`users`, `sessions`, `stored_prompts`), recreated from scratch every time the server starts.
- `frontend/src/data/subjects.json` is the subject list shared by the die and the backend warm-up.
- `Dockerfile`: a multi-stage build (Node builds the frontend, Python serves it).

## Running

You need Docker and a `.env` in the project root containing `OPENROUTER_API_KEY=...`.

```bash
scripts/start-mac.sh      # or start-linux.sh / start-windows.ps1
# → http://localhost:8000
scripts/stop-mac.sh       # or stop-linux.sh / stop-windows.ps1
```

## Development

```bash
# Backend (http://localhost:8000)
cd backend && uv run uvicorn app.main:app --reload

# Frontend (http://localhost:3000). next dev proxies /api to :8000
cd frontend && npm install && npm run dev
```

## Tests

```bash
cd backend && uv run pytest                       # never calls OpenRouter (a guard fails any test that tries)
cd backend && RUN_LIVE_LLM=1 uv run pytest        # plus exactly ONE real OpenRouter request, no retries
cd frontend && npm test
```
